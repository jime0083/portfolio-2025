 3. グラデーション定義
--------------------------------------------------------
・linear-gradient(to bottom, rgba(0,0,0,0.3), rgba(0,0,0,0))
   → 上から下へ黒フェード（ヒーロー等の上部オーバーレイ）
・linear-gradient(to right, rgba(0,0,0,0.3), rgba(0,0,0,0))
   → 左から右へ黒フェード
・linear-gradient(to bottom, rgba(52,52,52,0.3), rgba(52,52,52,0.8))
   → 濃グレーの縦グラデーション

 5. 備考
--------------------------------------------------------
・メインのブランドカラーは #D1597B（ピンク系）で統一されている。
  ボタン・見出し・枠線・アイコン強調に一貫使用。
・#ff6b81 はやや明るいピンクで、リンクや強調テキストに使用。
  #D1597B と役割が近いため、将来的に統一を検討可能。
・#333 と #343434、#444 は同系のダークグレー。
  表記ゆれがあるため CSS 変数化で統一することを推奨。
・現状カラーは CSS 変数（:root）で管理されておらず、
  各所にハードコードされている。上記4の変数化を推奨。

 6. 使用フォント一覧
--------------------------------------------------------
・Web フォント（Google Fonts 等）の読み込みは無し
・フォントファイル（woff/ttf/otf/eot）の同梱も無し
・すべて OS 標準フォントを指定するフォントスタック方式

--------------------------------------------------------
 6-1. 明朝体スタック（サイト全体の基本フォント）
--------------------------------------------------------
適用箇所: body（＝サイト全体の既定フォント）
分類    : 明朝体 / serif（日本語メイン）

  font-family:
    游明朝,
    YuMincho,
    "ヒラギノ明朝 ProN W3",
    "Hiragino Mincho ProN",
    HG明朝E,
    "ＭＳ Ｐ明朝",
    "ＭＳ 明朝",
    serif;

優先順位の意図:
  1. 游明朝 / YuMincho ……… Win/Mac 標準の游明朝
  2. ヒラギノ明朝 ProN ……… Mac 標準
  3. HG明朝E / ＭＳ明朝 …… Windows 標準
  4. serif ………………… 最終フォールバック

--------------------------------------------------------
 6-2. 欧文サンセリフ スタック（英語表記用）
--------------------------------------------------------
適用箇所: .loading-text（ローディング画面の英字テキスト）
分類    : サンセリフ / sans-serif（英語用）

  font-family:
    "Helvetica Neue",
    Helvetica,
    Arial,
    sans-serif;

--------------------------------------------------------
 6-3. 継承指定（inherit）
--------------------------------------------------------
適用箇所: AppPage.vue 内のフォーム/ボタン系要素（計4箇所）
値      : font-family: inherit;
意味    : 親要素（＝body の明朝体スタック）を引き継ぐ

--------------------------------------------------------
 7. フォントウェイト
--------------------------------------------------------
値               使用回数  用途
---------------  --------  ------------------------
font-weight: bold   26     見出し・強調・ボタン等
font-weight: normal  3     通常テキストへの明示的指定
（カスタムの数値ウェイト 100〜900 の指定は無し）

--------------------------------------------------------
 8. 備考
--------------------------------------------------------
・基本は「明朝体」でサイト全体を統一し、英字ロゴ/ローディング
  のみ欧文サンセリフ（Helvetica系）を使う構成。
・Web フォント未使用のため、表示フォントは閲覧環境（OS）に依存。
  游明朝が無い古い Windows 等では MS 明朝、最終的に serif に
  フォールバックする。デザインを厳密に統一したい場合は
  Google Fonts 等の Web フォント導入を検討可能。
・フォント指定も CSS 変数化されておらず、必要箇所で直接記述。
  --font-serif / --font-sans として変数化を推奨。
